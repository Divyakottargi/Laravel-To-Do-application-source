How Everything Connects

A quick summary of how the full system works together.

Frontend Layer

React renders the screens and forms, stores the auth token locally, and sends API requests through Axios.

Backend Layer

Laravel receives requests, validates data, creates tokens, protects routes, and applies business logic for tasks.

Database Layer

MySQL stores persistent data such as user accounts, tasks, and access tokens generated by Sanctum.
